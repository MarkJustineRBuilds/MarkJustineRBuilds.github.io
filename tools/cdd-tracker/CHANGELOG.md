# Changelog

## 1.0 - 2026-10-04

First public release.

- Case Desk with overdue-first case list, requirement ticking and status buttons (Mark received, Notify compliance, Complete, Reject)
- RM chasers: draft into the open Outlook email, or an RM Report with one draft and one Excel file per RM
- Notify compliance drafts with an optional compliance folder link
- Email Paste and Paste Import for adding requirements from any email; optional Outlook import for emails in a fixed format (off until `ImportSubjectPrefix` is set)
- Editable request, task and document types on the Lists sheet; email wording on the Templates sheet
- Optional client documents and compliance folder links (any web link or folder path)
- Start Here sheet, Check settings, Repair layout, Clear sample data and a run Log
- Sheet and workbook protection without a password; automatic backups
- Clean tab bar: seven everyday sheets visible; Settings, Lists, Templates, RM Directory and the guide open from Start Here buttons; history and log sheets hidden; maintenance mode (Alt+F8 > ToggleMaintenanceMode) shows everything
- Six fictional sample cases

### Planned for 1.1

- Renamable statuses: a fixed internal stage with a label you can rename, carried through to existing rows
